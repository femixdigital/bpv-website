# Bibliophile's Pen & Voice (BPV)

A mobile-first platform for booking personalized messages, calls, and letters.

## Planned Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Supabase

## Core Features

- Guest booking without customer accounts
- Multiple message and call services
- Manual OPay payment verification
- Admin dashboard for managing bookings
- Supabase authentication and Row Level Security

## Project Status

Project setup is in progress. See [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md) for the project requirements, architecture, design rules, and implementation plan.

## Development Environment

The project is developed using Termux on Android.
